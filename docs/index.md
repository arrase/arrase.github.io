# Life is the ultimate side project.

A collection of tools and applications built with passion.

<div class="projects-grid">

  <a href="/Raspiducky" class="feature-card">
    <i class="fas fa-microchip feature-icon"></i>
    <h3>Raspiducky</h3>
    <p>A modern, high-performance USB Gadget and DuckyScript/HIDScript execution appliance for Raspberry Pi, with zero-reboot ConfigFS support, dual scripting engines (JS & DuckyScript), and embedded web UI.</p>
  </a>

  <a href="/code-reducer" class="feature-card">
    <i class="fas fa-file-code feature-icon"></i>
    <h3>Code Reducer</h3>
    <p>A lightweight, high-performance command-line tool written in Go that automatically generates developer-friendly wikis for extensive repositories using local LLMs.</p>
  </a>

  <a href="/cud" class="feature-card">
    <i class="fas fa-users-gear feature-icon"></i>
    <h3>Cud</h3>
    <p>A lightweight, local-first OpenClaw-like multi-agent framework powered by Ollama. Build specialized agents with persistent memory, tool-calling support, and MCP integration.</p>
  </a>

  <a href="/eloquent-notes" class="feature-card">
    <i class="fas fa-note-sticky feature-icon"></i>
    <h3>Eloquent Notes</h3>
    <p>A system-tray utility for Linux that records voice dictations, structures them using a local Gemma 4 model via Ollama, and automatically saves them to your Obsidian vault.</p>
  </a>

  <a href="/ollama-agent" class="feature-card">
    <i class="fas fa-robot feature-icon"></i>
    <h3>Ollama Agent</h3>
    <p>A powerful command-line tool (CLI and REPL) that allows you to interact with local AI models through an Ollama-compatible API. Features tool support, vision, and memory.</p>
  </a>

  <a href="/Geotify" class="feature-card">
    <i class="fas fa-map-location-dot feature-icon"></i>
    <h3>Geotify</h3>
    <p>A modern, location-aware Android app for geofenced reminders, featuring a Jetpack Compose UI, interactive maps, and system-level Jetpack AppFunctions for assistant-driven control.</p>
  </a>

  <a href="/atomic-explorer" class="feature-card">
    <i class="fas fa-atom feature-icon"></i>
    <h3>Atomic Explorer</h3>
    <p>A desktop application for Linux designed for science popularization. Visually explore the atomic structure at different levels of complexity.</p>
  </a>

  <a href="https://arrase.github.io/blackhole/" class="feature-card">
    <i class="fas fa-circle-dot feature-icon"></i>
    <h3>Blackhole</h3>
    <p>Real-time relativistic simulation of a spinning supermassive black hole (Kerr metric) directly in the web browser using WebGL and GLSL shaders.</p>
  </a>

  <a href="/openclaw-voice" class="feature-card">
    <i class="fas fa-microphone-lines feature-icon"></i>
    <h3>OpenClaw Voice</h3>
    <p>A local Python CLI that turns UTF-8 text into cloned speech with Qwen TTS and delivers the final MP3 through Discord.</p>
  </a>

  <a href="/deepresearch" class="feature-card">
    <i class="fas fa-search feature-icon"></i>
    <h3>DeepResearch</h3>
    <p>An autonomous, auditable research agent that performs deep-dives into complex questions using local LLMs and web browsing.</p>
  </a>

  <a href="/gemma-translator" class="feature-card">
    <i class="fas fa-language feature-icon"></i>
    <h3>Gemma Translator</h3>
    <p>Lightweight translator for local document translation, unlimited document size, privacy-first.</p>
  </a>

  <a href="/OCR" class="feature-card">
    <i class="fas fa-file-pdf feature-icon"></i>
    <h3>OCR</h3>
    <p>Converts a PDF to text (Markdown) by rendering each page to an image and sending it through the deepseek-ocr model served by Ollama.</p>
  </a>

  <a href="/debateArena" class="feature-card">
    <i class="fas fa-gavel feature-icon"></i>
    <h3>Debate Arena</h3>
    <p>An autonomous, turn-based debate between two LLM agents (PRO vs CON), with checkpoint summarization and restriction injection to prevent loops and keep long debates coherent.</p>
  </a>

  <a href="/terraform-graphx" class="feature-card">
    <i class="fas fa-project-diagram feature-icon"></i>
    <h3>Terraform GraphX</h3>
    <p>A CLI tool that generates dependency graphs from your Terraform infrastructure and stores them in Neo4j for powerful querying and visualization.</p>
  </a>

  <a href="/delayed-shutdown" class="feature-card">
    <i class="fas fa-power-off feature-icon"></i>
    <h3>Delayed Shutdown</h3>
    <p>A simple GUI application to shut down your computer after a set of specified processes have finished executing.</p>
  </a>

</div>
